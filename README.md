MODIFICAÇÕES DO PROJETO
=======================

Esta versão foi planejada para ampliar as opções de jogo, facilitar os controles e deixar a experiência mais clara e atraente. As mudanças abaixo comparam o trabalho com o [projeto original de Jake Gordon](https://github.com/jakesgordon/javascript-tetris).

Modificações funcionais
-----------------------

1. **Controles mais flexíveis.** Segurar as teclas acelera o movimento lateral. A peça pode atravessar as bordas, girar perto dos cantos e ser ajustada por um breve período depois de pousar. Isso dá mais controle para posicionar peças em espaços apertados.
2. **Queda rápida com encaixe imediato opcional.** Espaço, S e seta para baixo iniciam a queda rápida. Um segundo toque encaixa a peça imediatamente. O jogador escolhe entre ajustar a peça durante a descida ou concluir a jogada sem esperar.

Modificações visuais
--------------------

3. **Interface de fliperama adaptável.** O painel, os controles e o tabuleiro se reorganizam para diferentes tamanhos de tela. Isso facilita jogar sem perder informações importantes em telas menores.
4. **Peças e efeitos visuais aprimorados.** O modo areia usa grãos animados em quatro cores distintas. Os modos também contam com efeitos de combinação e celebrações de linhas para destacar os resultados das jogadas.

Nova funcionalidade
-------------------

5. **Modo multiplayer local.** Duas pessoas podem jogar no mesmo teclado, em partidas clássicas ou de areia. O modo adiciona uma forma competitiva de jogar que não existia no projeto original.

Outras adições incluem os modos areia e competitivo, velocidade progressiva, recordes pessoais salvos no navegador, bônus por combos, novos efeitos sonoros e a janela “Sobre”, que credita o projeto original e informa sobre o uso de IA.
